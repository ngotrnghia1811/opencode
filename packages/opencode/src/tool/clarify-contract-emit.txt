Emit a generalised aki-clarify Contract YAML to .opencode/aki-clarify/. Call this after the clarifying-question ritual is complete with the final contract data.

The tool will:
1. Write the contract YAML to `.opencode/aki-clarify/contract-<timestamp>.yaml`
2. Emit a summary as a text part (when invoked via the task tool) so the calling agent can route to `target_agent`
3. Stop the current turn cleanly

The Contract must include `target_agent` naming the specialist that will consume it (aki-execute, aki-research, aki-inspector, aki-suggest, aki-algorithm, aki-orchestrator). Optional `params` carries per-specialist parameters as a key/value map.

Call this tool:
- After you have completed the clarifying-question ritual
- When you have resolved all unknowns or reached the maximum number of questions
- When the Contract is ready for the target specialist to consume

Do NOT call this tool:
- Before you have asked any clarifying questions
- Without setting `target_agent`
- If there are critical unknowns that still need resolution and you have questions remaining
